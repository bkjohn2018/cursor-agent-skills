# Analytics Storytelling

## When to Use
- Presenting analysis to business stakeholders.
- Translating charts into actionable insights.
- Requests for clearer story flow in reports.

## Workflow
1. Start with audience, decision, and desired action.
2. Choose visual form that best supports the specific message.
3. Remove clutter and non-essential elements that do not add meaning.
4. Focus attention using pre-attentive attributes (color, size, position, and emphasis).
5. Structure narrative as context, insight, implication, action.
6. Surface uncertainty, assumptions, and alternatives.
7. Close with explicit recommendation and next step.

## Storytelling With Data Principles
- Start with context and audience needs before chart design.
- Keep visuals simple: simple beats decorative.
- Use contrast intentionally to direct attention to what matters.
- De-emphasize supporting data and highlight the key signal.
- Titles should communicate takeaway, not chart type.

```markdown
## Supporting evidence
- Evidence 1
- Evidence 2

## Business implication
[So what]

## Recommended action
1. ...
```

## Quality Checklist
- Message starts with decision context, not methods.
- Visual form matches the analytical message.
- Clutter is removed unless it adds decision value.
- Attention is intentionally directed to key evidence.
- Each claim has supporting evidence.
- Trade-offs and uncertainty are acknowledged.
- Recommendation is specific and time-bound.
