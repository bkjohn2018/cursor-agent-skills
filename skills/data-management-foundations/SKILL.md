# Data Management Foundations

## When to Use
- Establishing or resetting enterprise data management scope.
- Defining how governance, architecture, quality, metadata, and security connect.
- Building a phased data management roadmap and target operating model.

## DMBOK Knowledge Areas Anchor
Use these anchors to organize recommendations:
1. Data Governance
2. Data Architecture
3. Data Modeling and Design
4. Data Storage and Operations
5. Data Security
6. Data Integration and Interoperability
7. Reference and Master Data
8. Data Warehousing and BI
9. Metadata Management
10. Data Quality Management
11. Data Management Maturity Assessment

## Workflow
1. Define business drivers and data management outcomes.
2. Assess current-state capabilities and pain points by knowledge area.
3. Define target operating model (owners, stewards, councils, controls).
4. Prioritize initiatives by risk, value, and feasibility.
5. Build a phased roadmap with metrics and governance checkpoints.

## Quality Checklist
- Recommendations map to explicit DMBOK knowledge areas.
- Roles distinguish accountability from stewardship.
- Roadmap balances quick wins and structural fixes.
- Success metrics measure business value and control effectiveness.
