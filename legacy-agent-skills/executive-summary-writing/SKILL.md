# Executive Summary Writing

## Purpose
Define how to write executive summaries for analytics governance packages.

## Scope
This skill covers the top-level summary for stakeholders, including:
- package purpose
- business value
- scope and boundaries
- key deliverables
- governance status

Before drafting governance documentation, check and apply:
.github/skills/finance-documentation-lifecycle

Use it as the source of truth for ISO 9001-inspired terminology, process/procedure/SOP distinctions, documentation lifecycle, and evidence/record expectations.

## Writing rules
- Keep it one to two pages maximum.
- Start with the business problem and value proposition.
- Use business-friendly language, not technical detail.
- Highlight what is ready, what remains, and what is required.

## Structure
1. Context and purpose
2. Key objectives
3. Scope and boundaries
4. Summary of deliverables
5. Risk and governance notes
6. Next steps

## Output expectations
- Provide a clear recommendation or status.
- Call out explicit non-goals.
- Align with the governance language in the package.
- Keep it concise, actionable, and executive-friendly.
